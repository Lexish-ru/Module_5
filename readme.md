# Курсовой проект-3

## Описание
Этот проект предназначен для получения информации о вакансиях с сайта [hh.ru](https://hh.ru), сохранения данных в базе **PostgreSQL** и выполнения аналитики с помощью класса `DBManager`.

## Функционал
- Получение данных о работодателях и их вакансиях через API hh.ru.
- Сохранение данных в базе PostgreSQL.
- Реализация класса `DBManager` для удобного доступа к данным.
- Выполнение SQL-запросов для аналитики вакансий:
  - Получение списка всех компаний и количества вакансий.
  - Получение всех вакансий с указанием зарплат.
  - Вычисление средней зарплаты.
  - Поиск вакансий с зарплатой выше средней.
  - Поиск вакансий по ключевому слову.

## Установка
1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/Lexish-ru/Module_5.git
   cd Module_5
   ```
2. **Установите зависимости с помощью Poetry:**
   ```bash
   poetry install
   ```
3. **Настройте PostgreSQL:**
   - Убедитесь, что PostgreSQL установлен и запущен.
   - Измените `src/config.py`, указав свои данные для подключения:
     ```python
     DB_NAME = "hh_vacancies"
     DB_USER = "postgres"
     DB_PASSWORD = "your_password"
     DB_HOST = "localhost"
     ```
4. **Запустите проект:**
   ```bash
   poetry run python main.py
   ```
